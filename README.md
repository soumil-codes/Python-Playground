### Python Fundamentals
- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Lists, Tuples, Sets, Dictionaries
- File Handling
- Exception Handling
- Object-Oriented Programming (OOP)

### Data Analysis
- NumPy
  - Arrays
  - Indexing and Slicing
  - Broadcasting
  - Mathematical Operations
- Pandas
  - Series and DataFrames
  - Data Cleaning
  - Filtering and Aggregation
  - Data Visualization Preparation

### Machine Learning
- Data Preprocessing
- Feature Engineering
- Train-Test Split
- Regression Models
- Classification Models
- Model Evaluation
- Basic ML Workflows

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/soumil-codes/Python-Playground.git
```

Navigate to the project directory:

```bash
cd Python-Playground
```

Run any Python file:

```bash
python filename.py
```
